# PE校园管理统计功能实现说明

## 功能概述

根据后端API文档，已成功实现PE校园管理系统的统计功能模块，采用统计大屏的专业设计风格。该功能仅对校级管理员和院级管理员开放。

## 实现的功能

### 1. 权限控制
- **校级管理员**：可以设置PE积分指标、查看全校统计数据、查看院系统计数据
- **院级管理员**：只能查看本院系的统计数据

### 2. 指标设置 (仅校级管理员)
- 设置周积分指标
- 设置月积分指标  
- 设置总积分指标
- 实时编辑和保存功能

### 3. 学校统计 (仅校级管理员)
- 显示学校基本信息和学生总数
- 全校整体达标率统计（周、月、总）
- 各院系达标率对比
- 院系排名（按综合达标率排序）

### 4. 院系统计 (校级和院级管理员)
- 显示院系基本信息和学生数
- 院系整体达标率统计
- 各班级达标率统计
- 班级排名（按综合达标率排序）
- 前三名班级特殊展示

## 技术实现

### 文件结构
```
src/
├── views/
│   └── Statistics.vue                    # 统计主页面
├── components/
│   └── Statistics/
│       ├── TargetsPanel.vue             # 指标设置面板
│       ├── SchoolStatistics.vue         # 学校统计组件
│       └── CollegeStatistics.vue        # 院系统计组件
├── services/
│   └── api.js                           # API接口 (新增peStatistics)
└── router/
    └── index.js                         # 路由配置 (新增/statistics)
```

### API接口
在 `src/services/api.js` 中新增了 `peStatistics` 模块：
- `setTargets(data)` - 设置PE积分指标
- `getSchoolStatistics()` - 获取学校统计数据
- `getCollegeStatistics()` - 获取院系统计数据

### 路由配置
在 `src/router/index.js` 中新增统计页面路由：
- 路径: `/statistics`
- 权限: 需要 `school_admin` 或 `department_admin` 角色

### 权限控制
- 使用现有的权限管理器 (`src/utils/permissionManager.js`)
- 在Dashboard中添加统计模块入口，仅对有权限的用户显示
- 在统计页面内部进行细粒度权限控制

## 设计特色

### 统计大屏风格
- **深色主题**：采用深蓝色渐变背景，营造专业的数据大屏氛围
- **玻璃拟态**：使用backdrop-filter和半透明背景实现现代化视觉效果
- **数据可视化**：进度条、百分比显示、排名徽章等直观展示数据
- **响应式设计**：适配不同屏幕尺寸，移动端友好

### 交互体验
- **实时刷新**：支持手动刷新统计数据
- **动画效果**：加载动画、悬停效果、进度条动画
- **状态反馈**：加载状态、错误提示、成功提示
- **权限提示**：无权限用户看到友好的提示信息

## 使用说明

### 访问入口
1. 登录系统后，在Dashboard主页面可看到"PE积分统计"模块
2. 点击模块卡片或直接访问 `/statistics` 路径

### 功能使用

#### 校级管理员
1. **设置指标**：在页面顶部的指标设置面板中编辑周、月、总积分指标
2. **查看全校数据**：查看整体达标率和院系排名
3. **查看院系数据**：查看本校所有院系的详细统计

#### 院级管理员
1. **查看本院数据**：只能查看本院系的统计数据
2. **班级管理**：查看各班级达标情况和排名

## 数据说明

### 达标率计算
- **周达标率**：根据学生总积分估算平均周积分，与周指标比较
- **月达标率**：根据学生总积分估算平均月积分，与月指标比较
- **总达标率**：直接比较学生当前总积分与总指标
- **综合达标率**：三项达标率的平均值，用于排名

### 排名规则
- 按综合达标率降序排列
- 前三名有特殊标识（🥇🥈🥉）
- 达标率低于60%的班级会有特殊标记
