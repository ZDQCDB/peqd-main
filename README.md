# 校园体育管理系统

一个基于Vue 3的校园体育管理系统前端框架。

## 项目概述

这是一个校园体育管理系统的前端骨架，包含完整的登录注册系统和9个主要功能模块。所有功能目前都显示"正在建设中"状态，等待后续功能开发。

## 功能模块

### 主要模块
1. **教学模块** - 教师教学管理和学生学习
2. **群体模块** - 群体活动和体育赛事
3. **训练模块** - 训练计划和体育成绩
4. **体测模块** - 体质测试管理
5. **器材模块** - 体育器材管理
6. **场馆模块** - 场馆预约和管理
7. **听课模块** - 听课管理
8. **健康讲堂** - 健康知识和讲座
9. **运动装备** - 装备共享和商城

### 详细功能

#### 教学模块
- **教师端**: 教学周历、教学教案、签到签退、演示视频、课后作业
- **学生端**: 签到签退、学习内容、视频学习、作业上交

#### 群体模块
- PE校园：举办比赛，参加比赛
- 早操管理
- 课外活动
- 校园阳光跑
- PE校园管理端

#### 训练模块
- **教师端**: 训练计划制定
- **学生端**: 训练计划完成
- PE分数管理

#### 器材模块
- **教师端**: 器材管理和分配
- **学生端**: 器材借用和归还

#### 场馆模块
- 校方场馆设置
- 学生场馆预约

#### 运动装备模块
- 运动装备共享
- 运动装备商城

## 技术栈

- **前端框架**: Vue 3
- **路由管理**: Vue Router 4
- **构建工具**: Vue CLI
- **代码规范**: ESLint

## 安装和运行

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run serve
```

### 构建生产版本
```bash
npm run build
```

## 使用说明

1. **访问系统**: 启动开发服务器后，浏览器访问 `http://localhost:8080`
2. **登录注册**: 系统首页为登录页面，可以注册新用户或使用现有账户登录
3. **功能模块**: 登录后进入主页面，点击各个模块卡片进入对应功能
4. **权限管理**: 系统支持学生、教师、管理员三种用户类型
5. **路由导航**: 每个模块都有返回按钮和面包屑导航

## 开发说明
